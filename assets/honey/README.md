# Honey graphic assets — yay's Honey Butter Pork Crisps

Vector honey elements for the Honey Butter bag. The `.svg` files open directly in
Adobe Illustrator (File → Open, or File → Place) as fully editable paths with
gradients — recolor, scale, and reshape freely. `png/` holds 4× transparent PNG
renders for quick placement or Photoshop.

| File | Use on the bag |
|---|---|
| honey-01-droplet | Single teardrop drip |
| honey-02-bead-drops | Scattered droplets (like around the crisps) |
| honey-03-drizzle | Curved pour/drizzle ending in a drip (top-left of mockup) |
| honey-04-swirl | S-curve drizzle accent |
| honey-05-puddle | Glossy honey pool to sit crisps/honeycomb in |
| honey-06-honeycomb-chunk | Large honeycomb piece with drip |
| honey-07-honeycomb-small | Small honeycomb piece (top-right of mockup) |
| honey-08-drip-border | Dripping honey band — can replace the wavy divider |
| honey-09-honeycomb-in-puddle | Honeycomb resting in a pool (center of mockup) |

Palette: highlight `#FFF4CC`, light `#FFD45A`, amber `#F2A516`, deep `#C9700A`,
shadow `#8E4705`; wax `#FFE08A` / `#F5BE45` / `#C98316`.

Regenerate: `python3 _source/gen_honey.py .` then `node _source/render.js .`
